# 对照研究稳健性协议（C1~C26）

## 为什么要有这一条（2026-09-18 一夜之间挡下 10 类错误，全部真实发生）

第 2 层「按 regime 分组看策略 E[R]」共三版，每一版都推翻了上一版，
**而每一版的错误都是由下面某条判据发现的**：

| 版本 | 推出的结论 | 被哪条挡下 | 真相 |
|---|---|---|---|
| v1 | 「预测续跌分支负贡献 / 口径错配」 | **C1** | 把 IM 池(1341) 与商品池(703) **混算** |
| v1 | 「BR3_5M 在 TREND 更优·稳健」 | **C3** | 笔级 ΔER=+1.24，**按日聚合后 Δ 仅 +0.12** |
| v2 | 「FAIL_BO/REVFAIL 每日只取第 1 笔」 | **C9** | 随机取 1 笔的分位 75~80% → **条件样本假象** |
| — | 「实盘与离线口径错配（4.17 倍）」 | **C6** | 拿 0.3×rng 单一公式去复算**两种 horizon** → 假差异 |
| 第3层v2 | 「R-trail/combo 优于 SWING8 现状」 | **C10c** | 冒烟 `--limit 200` 按信号生成顺序取 → 子样本≈最早一批；全量 4282 笔后**方向反转** |
| 第3层v2 | 「n_swing=1 为最优（更紧更好）」 | **C10b** | 峰位**分年漂移**（2022→1/2023→1/2024→5/**2025→8**/2026→1）+ **前后半漂移** → 判"无稳定最优参数" |
| BR3 归因 | 「每日只做第 1 笔能提高收益」（日均 +0.4823） | **C11** | **总产出仅 653.10 R = 做全部的 31.1%**（少做 2.36 笔/日 → 纯粹算术后果） |
| BR3 归因 | 「分位 100% 是随机基准重叠造成的」（我的假设） | **C9 附则** | 重叠确实达 46.2%，但**排除重叠后分位仍 100.0%** → 假设被实测**证伪** |
| 候选筛查 | 「6 个候选通过统计+随机基线」 | **C13** | 经既有裁定：5 个 `status=excluded`、4 个已撤推、1 个未登记 → **真实候选=空** |

**共同点**：这些错误**都能通过"看数字、比大小"的常规检验**——它们不是算错，是**不可比而比了**。

## 判据清单（下结论前逐条自问）

| # | 判据 | 可执行形式 | 不通过的表现 |
|---|---|---|---|
| **C1** | **池子声明** | 统计前**打印池组成**（谓词 + 各池条数 + 分层条数）；谓词取单一源常量，禁手抄 | 说不出"这批样本由哪些池/合约/品种组成" |
| **C2** | **禁跨池跨档合并** | 不同品种／不同 horizon／不同口径**分开报**；要合并必须显式声明并给出理由 | 用「全部样本」一把算 |
| **C3** | **按自然单位聚合** | 同一交易日内多笔 → 先折叠为 1 个观测（均值）再统计；**笔级差 ≠ 可用差** | Δ 在笔级很大、在日级很小（本次 6.9 倍） |
| **C4** | **四件套 + k\*** | 每组必报 E[R]／中位／去 top3／risk_median + k\*/n | 只报均值 → 被少数大赢骗 |
| **C5** | **分年 OOS** | 逐 year 复算；**任一年转负或符号翻转 → 标「不稳」，不得宣传** | 只看全样本（本次 2024 年完全反转） |
| **C6** | **等价性断言** | 声称「只加维度/未改口径」时，必须与旧产物逐位比对。**四条铁律**：<br>①**只比双方都有的字段**（比旧产物没有的字段 → 全判差异，假 FAIL）<br>②**比对的每一环都要对齐**（成本/费率/单位/扣减步骤漏一环 → 全判差异）<br>③**必须冻结数据快照**（数据源在两次运行之间被更新 → 最新一天必然差异，非口径漂移）<br>④**join 前必验键唯一性**（`(rule,dt)` 一类复合键**可能不唯一**：同一 rule 同一 bar 可达 3 笔 → 字典 join 静默错配、只留最后一个值；非唯一时须改**按键分组的多重集比对**或自算同源） | 报差异时先问"是口径变了，还是比较脚本自己错了"；**键不唯一时 join 结果不可信** |
| **C7** | **禁未来信息** | 分组标签只用 ≤ 交易时刻的数据；判定时点须早于绝大多数样本 | 用当日收盘信息解释盘中决策 |
| **C8** | **时间阈值分离** | 若分组依据在某时刻才成立，须**按该时刻切开**样本；并报"阈值前样本占比" | 阈值前 41.6% 的样本被误归入后段组（=稀释） |
| **C9** | **随机基准（★最易漏）** | 涉及"取子集/过滤/只做第 N 个"类规则，必须与**同口径随机取子集**的 bootstrap 分布比，报分位 | 只做 Δ 判据 → 把「样本变少」读成"规则有效" |
| **C10** | **可比性 + 峰位稳健性**（参数扫描/超参数选择必过）<br>**a** 单调性　**b** 峰位稳健性　**c** 抽样代表性 | **C10a**：指标随参数单调变化 → 判「机械效应/成本结构」，**禁称最优**；<br>**C10b**：出现内部峰值 → 须过「**分年峰位唯一** + **前后半一致** + **bootstrap 峰位概率**」三关，**且判据本身禁取单点**（须写成区间/谱：本轮实锤——N=250 单点判「无效」，而 N=60~180 全部有效）；<br>**C10c**：冒烟/子样本必须**随机或分层**，禁用"按生成顺序取前 N 笔"；且冒烟结论**只验证流程跑通**，禁作方向性判断 | 锯齿即宣称「有甜点区」；冒烟结论直接升格为方向性结论；<br>两组的「持有量/样本量」由**另一机制**决定却拿设定值当匹配依据 |

| **C11** | **笔数-日均陷阱（★最易误读）** | 比较**笔数不同**的两个方案时，**必须同时报「日均（每日 R 均值）」与「日总产出（每日 R 总和）」**；两者同向背离即判度量陷阱 | 用日均比较"做 N 笔" vs "只做 1 笔" → 把「少做几笔」读成"质量更高" |

| **C12** | **集中度外推门** | 分组/条件结论必报「**top-N 时间单元占该组总产出的比例**」+ k\*/n；**top5 占比 >70% 或 k\*/n <2% → 一律标『由少数时间单元主导，不可外推』** | 把"2024 年 RANGE 更好"当成组特征，实际是"2024 年 1 月那几天更好" |

| **C13** | **既有裁定优先（★筛查第一闸）** | 任何「候选/信号/形态能否用」的结论，**先查既有裁定**再谈统计：<br>① 找该实体的**谱系 id**（走单一源解析，见附则）<br>② 查 `rules.status` + `exclude_reason` + **`resolution_note`**（后者常记「已重测过」）<br>③ 查**排除集**所有副本（`EXCLUDE_RULES` 之类）与 `signal_status.json`<br>④ 报告必须给出「谱系 id + status + 命中副本 + **出处文件:行号**」<br>⑤ 已有 excluded/撤推/REJECT 记录者，新口径下的正结果**不得直接推翻**；须先说明「旧裁定为何在新口径下不适用」，否则**维持原裁定** | 统计判据全过就宣称"新候选" → 实际早已被排除/撤推（本次 6 候选全部落空） |
| **C14** | **多重比较校正（同时测 N 个变量时必过）** | 一次扫 N 个变量/口径 → 分位阈改为 **`1 − α/N`（Bonferroni）**，并**报出期望假阳性数 `α×N`**；<br>**禁止**在校正后仍以「最小 p 值」讲故事；单变量显著但未过校正者标「⚠️ 多重比较下不成立」 | 扫 8 个变量 → 期望 0.4 个假阳性；不校正就会把"第 8 名"采为发现 |
| **C15** | **比值指标的分母效应**（★跨对象比较绩效必过） | 比较「收益/风险」「收益率」「周转率」等**比值指标**时：①先报**分母分布**（中位/p95）；②**并列报绝对口径**（点数/金额）；③声明结论对应的**仓位口径**（固定风险金额 vs 固定手数） | 同一指标换因变量（比值 vs 绝对）→ **符号反转**（本轮实锤 P1：−0.29 vs **+0.33**），排名被分母而非质量主导 |
| **C16** | **层级混淆（within vs between）**（★变量关系结论必过） | 同一对变量在**笔级（对象内）**与**对象级（对象间）**可能**符号相反**（辛普森悖论）。任何"X 与 Y 的关系"必须①声明**分析层级**；②做**双层级对照**（各报一个 rho）；③符号相反 → 写成「层级依赖」，**禁**单层级结论外推 | 本轮实锤：rho(risk,R) 笔级 **+0.36** / 信号级 **−0.79**；rho(risk,PnL) 笔级 **−0.42** / 信号级 **+0.74** |

**C13 附则 — 跨命名空间取名（禁手写桥接）**：
同一实体往往有 **6 个命名空间**（register／family／gen／impl_5m／impl_day／bucket），
两两桥接**必须走既有单一源**（如 `core.alias_normalize.equivalences/resolve`），
**严禁**：手写 alias dict、拼接/剥离前后缀、大小写变换对齐。
**这类手写桥接通常已被机检扫描到** —— 遇到"手写桥接 N 个文件 ❌ 需修"的告警必须当场处理，不要忽略。
**自检技巧**：一次比对出现「**100% 不匹配**」或「**全部命中**」时，先怀疑**判定方式/语义空间**错了，
而不是直接采信；须取一个「已知必然命中」的项做**阳例自证**。

**C13 附则② — 作用域核查（2026-09-18 补；漏此步曾得出方向相反的整改方案）**：
「黑名单／过滤集／名录」是**按名字匹配**的，而名字的语义取决于**谁产出它**。
故在提出「某条该移出／该加入」之前，必须先查三件事：
① 该名字的**实际产出者**（源码里 `rule="X"` 或注册表映射）；② 它所在的**匹配空间**
（日线 rule 名？5m 实现名？注册键？）；③ **移出后实际放开了哪个对象**，该对象有无前视/数值缺陷。
本项目实锤：`EXCLUDE_RULES` 里的 `C1`/`C4` 只匹配**日线引擎**（5m 谱系产实现名 `PB50`/`HL_FLAG`），

而机器核查显示 29 名成员**全部**有日线产出者 → 该集合是自洽的「日线引擎黑名单」。
**机检入口**：`core/rule_scope.py --audit-scope`（逐组报「是否有对应日线产出者」，INFO only）。
**推论**：同名不同层 = 不同对象 → 与 C2（禁跨池跨档）同源，都属「不可比而比了」。

**C9 附则③ — 连续型替代 + null 带宽自证（2026-09-18 第 2 层 v4 补）**：
把连续/有序变量**切档**做对比会丢信息、且 Δ 的 null 分布极宽（本轮 p05~p95 宽达 1.18）。
**优先改做秩相关**（如 Spearman `rho(日变量, 当日均 R)`）——同样的数据，效力高数倍、读数更干净。
**并必须报 null 的 p05~p95 带宽**作为「本检验能测出的最小效应」自证：
- 观测效应 **< 带宽** → 结论只能写「**证据不足**」，**不得写「已证伪」**（把「测不出」当「没效应」是常见错）
- 观测效应 > 带宽且方向相反 → 才可用「已证伪」

**C2 附则 — 子群方向一致性（相消混合，2026-09-18 补）**：

### C9 / C10 / C11 的判定规则（务必按此解释）

- **分位 ≥95%（或 ≤5%）** → 该子集**确实特殊**，规则有机制依据；
- **分位落在 5%~95%** → 优势只是「少取了一部分」的产物，**不构成规则**（哪怕 ΔER>0 且 Δtop3>0）；
- **必报「日内笔数」等基数**：基数 ≈1 的组别，随机取 1 个必然≈取第 1 个，**天然落分布内、无区分度**。

**C9 附则 — 重叠检验（2026-09-18 BR3 归因补）**：凡"取子集 / 只做第 N 个"类随机基准，
**必须报出基准集与候选集的重叠比例**，并给「排除重叠」的对照版本。

- 重叠比例：候选是"日内第 1 笔「而基准是」每日随机取 1 笔"时，重叠 = **E[1/笔数]**
  （BR3_5M 3.36 笔/日 → **46.2%**）；基数越小重叠越高。
- **重叠存在 ≠ 结论被污染**：必须实测「排除重叠后分位是否改变」。
  本项目实测：重叠 46.2%，但排除后分位**仍 100.0%** → 假设**证伪**（该结论另有原因）。
- **报告要求**：两个分位（含重叠版 / 排除重叠版）并列写出，差值 <20pp 即可判「未污染」。

### C11 的判定规则

| 观察 | 判定 |
|---|---|
| 日均更高 + **总产出更低**（同向背离） | **度量陷阱**——日均差异是笔数摊薄的算术后果，**不构成策略优势** |
| 日均更高 + 总产出也更高 | 真实优势，可继续按 C1~C10 验证 |

**为什么**：「日均」= 每日 R 的**均值**（分母=笔数），「总产出」= 每日 R 的**总和**。
砍掉一部分交易，日均的分母同步变小 → 即使每笔质量不变，日均也会**机械上升**。
「每日只做第 1 笔」实测：日均 +0.7209（vs 做全部 +0.2385）**看似大幅改善**，
但总产出 **653.10 R = 2099.36 R 的 31.1%**（少赚 68.9%），且 **5/5 年份同向背离**。
⇒ **问「要不要少做某些交易」时，一律以总产出为准；日均只用于回答「单位交易效率」。**

### C12 的判定规则（集中度外推门）

| 观察 | 判定 |
|---|---|
| top5 时间单元（日/月）占该组总产出 **>70%**，或 k\*/n **<2%** | 标「**由少数时间单元主导，不可外推**」——组的「好/坏」实际是那几天的好/坏 |
| 集中度正常（top5 占比低、k\* 有厚度） | 可继续按 C1~C11 验证组特征 |

**为什么**：按 regime/时段/条件分组，会把**极端段落**的收益摊进该组；而极端段落天然极少
→ 组均值被少数观测主导。实测：2024 年 RANGE 组 680.88 R 中，**2024-01 单月占 76.7%**、
**top5 交易日占 91.1%**；同时 TREND 组 146 笔的 **k\*/n=0.68%（约 1 笔）**。
⇒ "2024 年 RANGE 更好"的真身是"**2024 年 1 月那几天更好**"。

**C12 附则① — 判据的「前提域」：总体为负时集中度**无意义**（2026-09-20 实测）**：
本判据（top-k 占比）**只在总体为正时有定义** —— 总体 E_R<0 时，"正贡献之和"与"总产出"符号相反，
占比会算出 `nan` 或负值，属**无声失败**（不报错，直接给无意义数；实测 FIRST_PULLBACK 四品种全 `nan%`）。
**固定动作**：跑集中度前**先判总体符号**；为负 ⇒ 集中度判据**不适用**，改问「是否**显著**为负」（见附则③）。

**C12 附则② — 「最强簇」必须三并列：显著／n 充足／双段同向（2026-09-20 实测）**：
实测 FIRST_PULLBACK：`run_hi` 簇 E_R 最高（训练 +0.792／盲测 +1.337）故被报告称"**最强簇**"，
但它**恰是样本最小的簇**（n=128/137，约为 `spike` 簇 732/559 的 1/4）；
而同型 **SA run_hi 恰恰出现「训练 +0.950 → 盲测 −0.496」**（过拟合现场）。
⇒ **固定动作**：称"最强"时**三项并列**（显著性 ≥2×SE ／ n ／ 训练-盲测同向）；
冲突时取「**三者都满足中 E_R 最低者**」作保守估计。**禁凭 E_R 单值称"最强"**。

**C12 附则③ — 「不可做」≠「负 edge」（2026-09-20 实测）**：
同一族裸族四品种，原报告一律记"不可做"，但统计上**分两类**：
- **不显著**（IM −0.043 t=−0.73／SA −0.076 t=−1.38）= **无 edge** ⇒ 处置「**加语境闸可救**」
- **显著负**（FG −0.534 t=−11.41／MA −0.202 t=−4.87）= **真负 edge** ⇒ 处置「**追做即亏，应回避**」
⇒ 混为一谈会**误弃可救族**。**固定动作**：报"不可做"前先看 `t = E_R/SE`。
（同源可复用工具：`_diag/_xcheck_ctx_tail.py` 通用族复核器 —— 输出即含 n／SE／t／多分位／
头部贡献／分年／训练盲测／按簇分解，**并已用 PAUSE_BAR 回归对照自证无漂移**。）

**C12 附则④ — 时间粒度：**年**粒度不得用于判定「稳健」（2026-09-20 实测，当场推翻同日结论）**：

**事故**：用**年**粒度判 HIGH2 lo3 簇稳健性 ⇒「MA 分年 4/4 全正 ⇒ 四品种唯一双段稳健」；
改**季度**粒度后**结论翻转** —— MA lo3 训练段 **88%**、盲测段 **94%** 净利来自**单季**；
**剔该季残值仅 14%／7%**（+0.0504 **t=0.58** ／ +0.0349 **t=0.35**，**不显著**）。
对照 IM/SA/FG 剔一季后仍保留 26%~52%（SA 残值 **t=3.23 仍显著**）⇒ **MA 反而最依赖单季**。

**为什么年粒度会骗人**：年把「1 季强 + 3 季平」压成「全年正」。同源证据：MA 全样本最大季
（2026Q3）贡献 **+341%**、正季仅 **4/17**；盲测段**样本量最大**的季（2025Q4 n=341）E_R **−0.001**。

**固定动作（四条）**：
1. **判「稳健」必须用季（或更细）粒度**；年粒度只可看长期趋势，**不得**作可复现性证据。
2. 必报 **段内最大季贡献占比**（该段内最大季净利 ÷ 该段总净利）——**全样本占比会掩盖分段内集中**
   （MA 全样本最大季仅 48%，看似正常；分到盲测段却是 **94%**）。
3. 必报 **剔主导季残值**：**t 掉到 <2 或残值 <30% ⇒ 原结论不成立**（不是"程度差"，是"无证据"）。
4. 产出**同时给两粒度**（年 + 季），**以季为判定依据**。

**判据依据**：C12 本就要求「top-N 时间单元占比」，但**"时间单元"的粒度**此前未被约束
⇒ 同一条 C12 在「年」与「季」下会给出**相反结论** ⇒ **粒度必须显式声明，且取足够细**。

**C12 附则⑤ — 附则④ 还缺第三个量：只剔「单季」会漏「连续季块」（2026-09-21 实测）**：

**事故**：`high2 × hi3 × IM 盲测`（n=2161）全量 E_R **+1.0411（t=9.95）**，
**剔主导季**（2025Q3）后仍 **+0.6550（t=6.33）、残值 63%** ⇒ 按附则④ **判「✅保留」**；
但该段正季只 **4/10**，且四个正季**恰好连续**（2025Q3→2026Q2）；
**剔该连续块**后 → **−0.4671（t=−12.16）** ⇒ **转负**。
⇒ 附则④ 的「单季」口径看不见**时序聚集**，会给出**过度乐观**的「保留」。

**固定动作（三条）**：
1. **附则④ 升级为三量并列**：① 段内最大季贡献占比 ② **剔主导季残值** ③ **剔最大连续同号季块残值**
   （「同号」= 时序相邻且全部同号；用**枚举区间取最大 sum**，别用 Kadane —— 季数少、可读性优先）。
2. **剔后符号必须显式报**：分母为正、分子为负时占比无意义（会算出 `-4737%` 这类噪声）
   ⇒ **一律写「转负」**，并把「剔后转负」当作**比残值更硬的不成立证据**。
3. **判定必须显式、且分支顺序属于语义**：
   - ⚠️ **`nan < 0.30` 为 `False`** ⇒ 「剔后无样本/残值不可算」会**偶然落到「✅保留」**（实测两次）。
     偶然正确的判定＝没有判定 ⇒ **前提域必须显式先判**。
   - ⚠️ **顺序**：必须先判「**总体 E_R ≤ 0 ⇒ 不出判定**」（附则①前提域），**再**判「剔后无样本」。
     实测反例：`BEAR_FLAG×lo3×IM 盲测` n=**1**、E_R=**−1.0168**，顺序写反被判「**全段皆正 ✅保留**」
     —— 一个**负的单样本段**被判成最稳健。
   - 「剔后无样本」的正确语义是 **「全段皆正（找不到负季可剔）⇒ 最强稳健」**，
     **不是「判据不适用」**（两者都会走到 `n1=0`，必须靠总体符号区分）。

**判据依据**：附则④ 立命之本就是「**粒度不足会掩盖结构**」；而「单季」是**比季度更粗**的一层粒度
⇒ 同一条附则④ 在「单季」与「连续季块」下同样会给出**相反结论** ⇒ **附则④ 自身必须先过自己的门**。

（可复用工具：`_diag/_xcheck_ctx_tail.py` 表4c/表4d + `quarter_verdict()` 判定单一源 +
`--selftest` 12/12；簇过滤支持 `dim=value`（`day_pos`/`spike_cls`/`run_cls`）；
**回归自证**：`high2 × lo3` 对照 2026-09-20 r2 报告逐项一致。）

**C5 附则② — 去混杂对照：量级 vs 符号（2026-09-18 补）**：
当候选变量是**带符号量**（如「前一日总R」），而收益又呈**强正偏态**时，
效应极可能只是「**量级/波动聚类**」的表现（量大日期望 R 本就更高），而非「符号持续性」。
**固定动作**：①与 `|该变量|`（量级版）**并列测效力**；②做**偏秩相关**（控制量级版）③分档看效应量是否同阶。
只有当**偏相关控制后仍显著**，才可排除「代理」解释。
（本轮实锤：`prev_dayR` 控制 `|prev_dayR|` 后偏秩相关 **+0.1318 / 分位 100%** → 才敢称符号持续性。）

**C11 附则 — 「收益规则」vs「风控规则」+ 量纲纪律（2026-09-18 补）**：
「少做」类结论（过滤/停手/降频）**即使六项判据全过**，仍须另算**落地形态下的总量**：
组间 Δ 是**比较**，落地是**去掉一部分后的总量** —— 两者判据不同。
- 总量**上升** → **收益规则**（可提候选）
- 总量**下降**而效率上升 → **风控/质量规则** → 须按**回撤/最差月/收益回撤比**评估，
  **不得**表述为「提高收益」；属资金域，须拍板
**⚠️ 量纲纪律（本轮两次踩坑）**：
① **总量口径只有一种 = 累计 R**（或日总产出序列之和）；**禁**用 `per-trade 均值 × 天数`；
② 也**禁**拿子集的「单位交易日日均」与全体的「单位交易日日均」直接比（分母 949 vs 652 不同）——
   这两种都属 C11 陷阱变体，且**可能给出方向相反的结论**（本轮一次得 −8.9%、一次得 +32.6%）。
③ 报结论时六项并列：**累计R / 单位日效率(标分母) / 每笔均值 / 最大回撤 / 最差月 / 收益回撤比**。

**C11 附则② — 自指性指标必须跑「顺序化模拟」（2026-09-18 补）**：
指标若含**策略自身历史**（前一日盈亏／连亏／回撤／胜率…），则规则的落地会**反过来改变指标取值**。
**固定动作**：① **顺序化模拟**（逐日、按**实际决策**更新指标，禁静态分组）② **检查是否死锁**
③ 给出**解耦约定**（通常 = **影子账本**：停手日照常记录信号假设 R、不下单）④ 量化解耦前后差异。
本轮实锤：`prev_dayR` 若按「最近一个**实际**交易日」取值 → 停手日不更新指标 → **永不停复**，
模拟中 **948 日后仅剩 1 个交易日**；改为影子账本后与静态理想切分仅差 **−0.0023 日均 / −4.12R 累计**（可忽略）。
⇒ **自指性不只是精度问题，而是可能让规则完全不可运行**，且**静态分组检验永远看不出来**。

### C5 附则：归因研究的方向性判据（★反证法）

做**归因**（"X 是不是 Y 造成的"）时，正确的检验是「**移除 Y 重算**」，且**预期方向必须事先写死**：

| 移除 Y 后 | 结论 |
|---|---|
| 差异**变小**（或消失） | Y 是（或部分是）解释 ✅ |
| 差异**变大或不变** | **直接排除 Y**，无需再找机制 ❌ |

实测：怀疑 2024 反转由**稀释**造成 → 改用 v2 纯口径（移除稀释）→ Δ日均 由 −0.3558 变为
**−0.8642（变大）** ⇒ **稀释不是解释**，当场排除。
**若不写死方向**，很容易把「移除后仍为负」读成「稀释是主因」（先有结论再找理由）。

### C7 附则：代理变量可得性必须**按样本时刻逐笔判定**（★ 隐蔽前视）

构造「事前代理」（用某个可观测变量预测目标）时，**最易犯的错不是故意用未来，而是用"当日某段"**：

| 写法 | 为什么含前视 |
|---|---|
| `open_move = \|当日首根close − **当日末根close**\| / open` | 末根 close = **当日收盘** = 未来 |
| `amp = **09:30-10:30** 段振幅`，而样本发生在 **09:40** | 09:40 之后的行情此时不可得（**部分前视**，最隐蔽） |
| ✅ 正确 | 窗口必须**严格早于该样本的时刻**（逐笔/逐行判定，不能按「当日」一刀切） |

**前视对照法**（本轮新立，用于自检）：同时计算一个**必然含前视**的代理（如「当日全天振幅」），并列报出：

- 安全代理 rho 远低于含前视代理 → 前者可判性差，**含前视者不可用**（本轮：安全 ≤0.095 vs 含前视 **0.4018**）
- 两者接近 → 疑似该「安全代理」实际同义反复或仍含前视

**实证**：该法当场推翻了我自己提出的「高机会日」线索 —— v1 代理 rho=0.3872 属前视产物；
改用前视安全口径后最强仅 **−0.0946** ⇒ **线索不可执行，关闭**（AUD-309/310）。

### C16 的判定规则（层级混淆 / 辛普森悖论）

同一对变量在不同**聚合层级**上关系方向可能相反：
- **笔级（within）**：同一对象（信号/品种）**内部**各笔之间的差异
- **对象级（between）**：**跨对象**的均值差异

**判据**：
1. 任何"X 影响 Y"的结论**必须声明层级**（within / between / 混合）
2. 须做**双层级对照** —— 同一条关系分别按笔级与对象级计算，**两个 rho 都报**
3. 若**符号相反** → 结论必须写成「**层级依赖**」，**禁**用单层级结论外推到另一层级
4. **外推禁令**：笔级结论（"宽止损的笔 R 更高"）**不得**用于对象选择（「选宽止损信号」）

**本轮实锤（2026-09-18，IM 池）**：

| 层级 | rho(risk, R) | rho(risk, PnL 点数) |
|---|---|---|
| 笔级（4280 笔） | **+0.3603** | **−0.4171** |
| 信号级（18 信号） | **−0.7915** | **+0.7420** |

⇒ 按 R 排名选到**小结构**信号（GP3/REVFAIL），按绝对口径选到**大结构**信号（MMT/MC8/AI1）
—— **两者相反**。混合层级统计（把 4280 笔与 18 个信号当成一个总体）**不可解释**。

### C15 的判定规则（比值指标的分母效应）

`R = PnL / risk` 一类「比值型绩效」**同时反映分子与分母**。当分母（风险／暴露／规模）在对象间
分布不同时：① 排名可能由**分母**而非**分子（质量）**主导；② 同一指标换口径（比值 vs 绝对）
可能**符号反转**。

**判据**：
1. 跨对象比较前**报分母分布**（中位/p95）—— 本轮实锤 risk p5=7.6 / p95=63.6（**差 8 倍**）
2. **并列报绝对口径**（点数/金额）；两口径排名秩相关 **|rho| < 0.8 → 必须双报**
3. 结论必须声明**仓位口径**：固定风险金额（=比值口径，答「效率/风险预算」）
   vs 固定手数（=绝对口径，答「每笔实际金额」）
4. 口径差异信号须过**分年检验** —— 防单年主导
   （本轮 YDAY_FAIL 位差 −4，但其"绝对口径第 2"几乎全来自 2025 一年 → **位差作废**）

### C2 附则②：水平量必须**滚动分位化**（★ 否则测的是时间趋势）

「水平量／绝对量」（价格、波动点数、成交量、点位）在非平稳序列上**隐含时间趋势**。
本轮实锤：同一 `rng14` ——
- **绝对点数** rho = **+0.0998**（C9 分位 99.5%，**过 Bonferroni 阈**）
- **滚动分位** rho = **−0.0500**（分位 7.0%）
⇒ **符号相反**。凡「水平量」入秩相关/分组/门控，**必须先滚动分位化**（窗口只含 ≤d−1），
并核对**禁用全样本 `rank(pct=True)`**（含未来信息，违 C7）。

### C10b 的判定规则（参数扫描务必按此解释）

| 观察 | 判定 |
|---|---|
| 峰位在**分年**或**前后半**之间不一致 | 一律判「**无稳定最优参数**」→ **维持现状**；**即使 P(该参数优于现状)=98% 也不得改参数** |
| bootstrap 中「**该参数为最优**」的概率 <80% | 峰位本身是抽样噪声，数字不可用 |
| 峰位唯一 + 前后半一致 + 概率高 | 才可提「候选」；**落地仍走生产侧 approve** |

**为什么 P(优) 高也不能改**：`P(n=5 > n=8)=98.2%` 与 `P(n=5 为最优)` 是**两个不同的问题**。
前者只说明「比现状好」，后者才说明「该值对」；本轮实测前者 98.2%、后者仅 14.9%（峰位归 n=1 的 52.2%）
——**方向性成立 ≠ 存在可落地的具体参数**。此时正确动作是：**不动参数，登记为观察项**。

### C10c：抽样代表性（冒烟/子样本）

- **禁用"按生成顺序取前 N 笔"**：本轮实测 `--limit 200` 取到的是**最早的一批信号**
  （信号字典序靠前的族），构成与全体显著不同 → 冒烟显示"R-trail 更优"，全量 4282 笔后**方向反转**。
- 冒烟**只用于验证流程跑通**（能否跑完、有无报错、产物格式对不对），**禁止用于方向性判断**。

    **修法**：①**验证链第 0 步改为「样本量预检」**（n<30 → 判「证据不足·待积累」并停手，
    不进三段验证）；②n≥30 且 <100 须报 CI + 年份覆盖数，跨年一致 <3 年不得判 verified；
    ③孵化器侧建议登记时给出历史匹配量，n<30 标为「证据不足·待积累」而非 pending。⇒ 判据 **C22①**。

21. **连击型候选不先分层，把"预测恰好一直错"的自相关当成动作增量**（2026-09-28，同轮 INC_039 条件2）：
    候选写「13:00-14:00 ∧ **连续 3 根** pred 与上一桶 act 相反 → 下一桶默认输出反向」。
    若直接算配对净增量得 **+38.88pp** 就收工 —— 但无法回答：这究竟是"连续失准"这个条件的功劳，
    还是**反手动作本身**、或**13:00-14:00 时段本身**的属性？
    **分层破局**：按 `prev_pred 是否正确` 切开 ——
    前桶对 → 本桶沿用 **85.68%** / 反手 11.34%（n=11365）；
    前桶错 → 本桶反手 **73.45%** / 沿用 9.24%（n=9447）
    ⇒ **V1 的 act 序列存在强自相关，且方向由前桶正确性决定**；区内前桶正确率仅 **11.03%**
    （全样本 50.98%）⇒ "连续 3 根与上一桶实际相反"正是"连续失准"的可靠探测器。
    **再补同域其余退化对照**：n=9842 净 **−24.38pp** ⇒ 真净增量 **63.26pp**（非自称的 38.88pp）。
    **再补镜像对照**：连续 3 根"一直对"（n=4698）净 **−47.59pp**，与 +38.88pp 完全对称
    ⇒ 驱动量确为"是否失效"，非单向偏置。**限定条件必要性**：去掉 13:00-14:00 后
    全日版净 **+41.84pp > +38.88pp** ⇒ 时段限定属冗余。
    **修法**：①连击型候选**先按前桶状态分层**取专属基准；②补同域其余退化对照算真净增量；
    ③补镜像对照验方向对称；④做限定条件必要性检验；⑤结论须如实定性为
    「**引擎自相关结构**」（可作 bias 层修正）而非独立市场知识。⇒ 判据 **C22②**。
    **连带（本链已成熟）**：C17→C18→C19→C20→C21→**C22** 已成完整的候选验证链，
    与 id=235/241/247/325/383/385/392/393/397/398/399 经验条目一一对应。

## 使用方式（最小流程）

```
0. **样本量预检（先于一切，含 C13）**            （C22①：n<30 → 判「证据不足·待积累」并停手；
   n<100 须报 CI + 年份覆盖数，跨年一致 <3 年不得判 verified）
1. 声明池 + 打印组成            （C1/C2）
2. 定自然聚合单位（本项目的默认：交易日） （C3）
3. 每组跑 evalkit.report()      （C4：四件套+k*，唯一出口，禁自实现）
4. 分年复算 + 标负年            （C5）
5. 若声称"只加维度"→ 逐位比对旧产物 （C6，只比共有字段）
6. 检查分组标签的时点            （C7/C8）
7. 若是「取子集/过滤」类 → 加随机基准 bootstrap （C9）
7b. 若是**参数扫描/超参选择** → 过 C10a（单调性）+ **C10b（峰位稳健性：分年唯一 + 前后半一致 + bootstrap 峰位概率）**；
   冒烟必须**随机/分层**（C10c），且冒烟结论只验证流程跑通
7c. 若两方案**笔数不同** → 同时报「日均」+「**日总产出**」，同向背离即判度量陷阱（C11）
7d. 若是**分组/条件结论** → 加**集中度检验**（top-N 时间单元占比 + k\*/n），过高即标「不可外推」（C12）
7e. 若是**归因**（"X 是不是 Y 造成的"）→ 做「移除 Y 重算」，**预期方向事先写死**：变小=Y 是解释；变大/不变=排除 Y（C5 附则）
7f. 若用了**事前代理** → 窗口必须**严格早于每个样本的时刻**（禁「当日某段」），并加**前视对照**（C7 附则）
7g. **若是「候选/信号能否用」类筛查 → 先跑 C13（既有裁定）**：解析谱系 id → 查 status/exclude_reason/
   resolution_note → 查排除集全部副本 → 给出"出处文件:行号"；已有 excluded/撤推记录者禁止直接推翻
7h. **实现完成后逐条回对设计判据**：把设计里写死的判据表达式与代码逐条比对。**实现时「顺手加严」判据比「放宽」更危险** —— 放宽会被后续证伪暴露，加严造成的「误杀」没有任何下游信号（本轮实例：给 J2 私加一条 Low 日总≤0 → 把一个成立的风控规则判死）。判据要改必须走**设计变更**（改文档 + 写理由），禁在代码里顺手加条件
7i. 若参数由**扫描/挑选**得到 → 必过**时间切分**（IS 选参 → OOS 验证，**OOS 不再调参**）；若样本外失效 → 在 OOS 上**重算全网格**以区分「**过拟合**」（OOS 有可用参数）与「**状态依赖**」（OOS 无可用参数）；并并列报**两段基线水平**（否则市况差异会被误读为规则变差）
7j. **若候选含动作子句（改判/停用/剔除）→ 先过 C18 定动作类型，再过 C17/C19**：①**先定类型**——候选声明的动作是「反手/改判」还是「剔除/停用/降权」；②剔除型 → 做**偏误定位**（动作针对的标签 L 在区内实际发生率 vs 全样本基准，差 <3pp 即判动作指向错误）+ 选择性用**单位覆盖增益**（Δpp ÷ 覆盖损失%）；反手型 → 基准取**同域其余样本的同动作兑现率**；③**两类口径并列输出，只按声明的类型下判定**。**顺序不可颠倒**——定位不过时，净增量算得再大也无意义；类型选错时，**结论会直接反向**
7k. **若子集定义含结果量（act／"V1 判错"／预测与实际不符）→ 过 C19**：①区内命中率标「**构造性、无信息量**」，禁作识别力证据；②先算全样本**同 act 形态的转移率基线**（`P(次桶 | 本桶act)`、`P(次桶 | 连续2桶同向act)`），动作兑现减该基线，**<3pp 判被自相关完全解释**；③relabel 型动作（如 sit 降级）须**直检目标标签转移率**，不得用行为代理口径顶替；④自相关异常高（>80%）时复核结果量定义有无机械续期结构
7l. **若候选正文含对不上号的量化词 → 先过 C20（口径失真）**：①做**量词-字段对照**，字段表里找不到即标「口径失真」（禁直接判"不可判"了事）；②用候选**自身机制文本里的数值**去反查阈值出处（数值精确吻合即可锁定真实口径）；③按真实口径选 **≤t 可盘中化**代理，并显式标注「代理口径 ≠ 原文口径」；④口径存疑者**并列多口径**输出，禁单口径定论
7m. **若动作形如「一律判 X」（替换型）→ 再过 C21**：①先报 **X 的全样本基准率**；②**同桶位配对对照**「替换后命中(`next.act==X`) vs 沿用基线命中(`next.ok`)」，净增量 **<3pp 无效、为负有害**；③**偏误定位定方向**（区内实际分布 vs 原预测分布，**欠发**谁就偏向谁）；④多口径须逐口径分别做
7n. **若候选形如「连续 N 根某状态」→ 动作（连击型）→ 过 C22②**：①**先分层**——按 `prev_pred 是否正确` 把样本切开，分别统计「次桶反手率 / 沿用率」，得到该候选的**专属对照基准**（本例：前桶对→沿用 85.68% / 前桶错→反手 73.45%）；②再补**同域其余退化对照**（C19②）算真净增量（本例 38.88 − (−24.38) = **63.26pp**）；③再补**镜像对照**（连续 N 根"一直对"）验方向对称（本例 −47.59pp，完全对称）；④做**限定条件必要性检验**（去掉时段限定后 +41.84pp > +38.88pp ⇒ 限定冗余）；⑤定性措辞须区分「引擎自相关结构」与「市场知识」
8. 全部通过后才写结论；任一条不过 → 标「不稳/不成立」，**并保留该路径的记录**
```

**与被否结论的关系**：被 C1~C9 挡下的候选**不要删除**——
它们是「已排除路径」的证据（本项目做法：登记 finding + 归档为「待验/不成立」），
避免后来者重新踩坑。

## C23 · 「控制变量」必须先自证只改了一处（parity 断言）

**适用**：任何"只替换一个判据、其余照抄"的对照（`close`→`high`、参数 A→B、过滤开→关）。

| ⛔ 禁止 | ✅ 要求 |
|---|---|
| 用**生产函数**当 baseline、用**复刻件**当变体，两者从不逐条比对 | 变体与 baseline **都**由复刻件产生；先与生产件 parity |
| 自查「我只改了 N 处比较」 | 集合相等才算证明（自查不可信） |
| 不相等就打印一行继续跑 | 断言失败 ⇒ 立即停止，不得出数 |

**实证（2026-10-21，E-37）**：复刻件同时改了「触发口径」与「腿分隔口径」两处
⇒ 报出的召回 **49.5%** / 精确 **67.8%** 全部作废，单变量正确值是 **54.6% / 60.8%**。
工具：`core/selfcheck_kit.assert_parity()`（集合语义要求元素可哈希 ⇒ 信号列表先转 `{(bar, dir)}`）。

**同日连带事故（E-39）**：批量补标脚本一行三元式优先级写错，把 59,793 B 的登记册覆盖成 1,144 B
⇒ 补一条：**批量改写必须事务化**（备份 → 临时文件 → `os.replace` → 读回断言；计数用行首正则，
不用 `text.count()`）。

## C24 · 断言「这个闸没起作用」之前，先报**放行率**

**适用**：评价任何过滤器 / 门控 / 否决闸是否空转。

1. 报 **候选数 → 通过数 → 放行率**，并写清分母层级（bar / 信号 / 交易日）
2. **先问「是不是同一件事」，再问「松还是紧」** —— 两个不同事件的放行率不可比大小
3. 只有放行率接近 100% 才能说「近似恒真」；否则只能说「它在做另一件事」

**实证（2026-10-21，E-38）**：曾断言 `_line_break_long` 近似恒真（理由「回调必破趋势线」），
实测放行率 **54.2~58.5%**（4 品种）；按原著语义重写的线规则是 **28.6~31.2%**
⇒ 两者都不是空过滤，而是**判的不是同一件事**（向下跌破牛趋势线 vs 向上突破回调的熊微趋势线）。

## C25 · 语境分桶前必须断言**方向同质**

**适用**：任何按「语境变量」（距均线、区间位置、波动率、时段…）给信号分桶的测量。

**为什么**：语境变量与方向**强耦合** —— 同一个 `(entry−MA)/σ`，对多头是"溢价"，对空头是"折价"；
把多空混在一桶里，桶内语义会被反向样本稀释甚至翻转。

**机检**：分桶前 `assert len({r["dir"] for r in rows}) == 1`；要做镜像，就**分开跑**再并列报。

**实证（2026-10-21，E-40）**：首版把 11,744 条多头 + 11,372 条空头一起分桶（n=23,116），
"均线上方最高三分位"的中位被空头拉平（−0.175σ）；只取多头重跑后变成 **−0.367σ**，
且三个桶呈**单调**（+0.256 / +0.180 / −0.367）。**混方向的结论既不是多头的、也不是空头的。**

## C26 · 模式证据必须是相对「同 regime 基线」的**增量**，不是相对 0 的绝对关系

**适用**：任何「某形态/信号在语境 X 下更好 / 更差 / 更该反手」的结论。

| ⛔ 禁止 | ✅ 要求 |
|---|---|
| 只报信号组的 ρ 或中位「显著偏离 0」 | 报三列：**同 regime 非信号基线组** / 信号组 / **Δ 及 CI** |
| 两个 ρ 量级接近就写成「一致」 | 量级接近 = **没有增量**；判定只看 Δ 的 CI |
| Δ 符号与预期相反时略过 | 必须明写「符号相反」 |

**机检**：结论段必须同时出现「基线」「Δ」「CI」三项；缺任一项视为未验证的比较。

**实证（2026-10-21，E-41）**：先测出「弱趋势里越靠均线上方、多头 H2 后续越差」
（T=0.25、h6、ρ=−0.118、n=1,105），据此写成"与原著 p291 方向一致、弱支持"。
补做同 regime 全 bar 基准（ρ=−0.057、n=55,469）与差值检验后：
H2 组 ρ=−0.029（n=1,854），**Δ=+0.030（95%CI −0.018~+0.076）**，9 格全跨 0，
且在 T=0.50/1.00 的 h6 上 Δ **为正** ⇒ 「H2 更差」不成立，它是**全体 bar 共有的均值回归**。
⇒ 结论撤回。**这条错在把"语境变量有用"当成了"形态有用"。**
