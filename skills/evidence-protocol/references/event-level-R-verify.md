# 事件级实测 R 验证协议

> 出处：2026-09-23 B62 实证。一个「P=41.9% ⇒ E[R]=+0.257」的结论，换成真实出场 + 实测成本后
> **转负** —— 前一轮的 `E[R]=3P−1` 里，**P 是实测的、赔率却是假设的，两边不同源**。

## 0. 三件套反模式：出现任一 ⇒ 结论不可信

| 反模式 | 表现 | 后果 |
|---|---|---|
| **假设赔率** | 用 `E[R] = (1+rr)·P − 1` 代入假设的 rr | 赔率与 P 不同源 ⇒ 违反「长对长、短对短」 |
| **零成本** | 回测不扣费，或费率内联手写 | 阈值附近的 edge 全部消失（实测：日内平今口径下整族转负） |
| **代理真值** | 用「N 根内未收回区间」这类**过程量**当成交结果 | 过程成功 ≠ 这笔交易赚钱（止损可能在成功前被打掉） |
| **成本分母混淆** | 含成本的 R 做分组，而分组变量与 risk 相关（如 bar 大小 ∝ risk） | **毛期望与该变量无关，净 R 也会自动跟它正相关** ⇒ 造出显著（详见 §4.8） |
| **分母异常小** | risk（入场价与止损价之差）被上游"兜底逻辑"钳到极小（如 ±2×tick） | **R 被放大百倍** ⇒ 极少数样本即可**翻转整条结论的符号**（详见 §4.10） |

**一句话判据**：**P 从哪来、赔率从哪来、成本从哪来 —— 三者必须同源且都是实测**；
**并且成本一旦进了 R，就要问它是否与你的分组变量共变。**

## 1. 正确构造（缺一不可）

1. **事件**：判据给方向 + 特征；**特征只用事件当时可得量**（禁后视）
2. **入场**：用 `o[i+1]`（下一根开盘）；回调入场须显式定义回吐比例
3. **止损**：**结构极值 ± tick**（自事件起至入场前一根的极值）—— 参数自由，避免手拍 ATR 倍数
4. **出场**：逐根撮合，**同根双触取止损（保守）**；到期未触 ⇒ 该根收盘平（实现 R）
5. **成本**：**走公共库唯一实现**（禁脚本内复制费率；实测教训：脚本内复制 ≈ 30 处，费率口径必然分叉）
   - 日内/跨日**费率不同**（IM 平今 2.3‱ vs 平昨 0.23‱ ⇒ **10×**）——先确认持仓周期口径再算
6. **R 归一化**：`R = (exit − entry)·dir / |entry − stop| − cost_R`

## 2. 统计口径（三条铁律）

- **R-A1 日聚合**：同一天多个事件高度自相关 ⇒ **分组比较前先按交易日聚合**（笔级 n 会虚高数十倍）。
  实测折损：笔级 E[R] 0.214 → 日级 0.161（≈ −25%）。
- **选优 = 分年最差年，不是均值**。均值与最差年**背离**时，背离本身就是结论（= 状态依赖），
  别急着分层救回 —— 先当作「不可用」，分层只能用于**诊断**，不能用于**选优**。
- **脆弱性判据**（`evalkit`）：`trim25% ≤ 0` 或 `k* < 1%` ⇒ 收益全靠少数几笔 ⇒ 禁入生产；
  `k* ≈ 3~10%` ⇒ 强正偏态（趋势跟随典型）**必须完整执行、禁截右尾**，同时仍是脆弱证据。

## 3. 稳健四验（不跑完不许下结论）

| 验 | 做法 | 通过标准 |
|---|---|---|
| **同源断言** | 两个独立实现算同一配置，逐位比对 | 完全相等（不等 ⇒ 口径已分叉，**拒跑**） |
| **IS/OOS 时间切分** | 训练期 / 盲测期各算一次 | **两侧同号为正**（符号翻转 = 不稳定） |
| **shuffle 随机对照** | **只打乱被检验的那个标签**，保留其他过滤，重复 ≥200 次 | 真实值分位 p < 0.05；否则该标签的增益**不显著** |
| **邻域单调性** | 参数分档看 E[R] 走势（不是只测一个阈值） | 单调或至少单峰平滑；**非单调 ⇒ 阈值挑选嫌疑** |

**多重检验意识**：扫 N 个配置只过 M 个 ⇒ 先算通过率。实测 486 选 3（0.6%）⇒ **默认过拟合**，四验缺一不可。

## 4. 实测踩坑（全部真发生过）

1. **「回调入场更优」是错觉**。实测 追突破 ≫ 浅回调 ≫ 深回调：回调入场止损更近 ⇒ 风险小 ⇒
   **成本占 R 的比例更大**；且回撤本身 = 突破正在失败（Brooks：most breakouts fail）。
2. **目标不是越小越好**：`3R > 2R > 1R`，1R 全负 ⇒ 砍右尾 = 直接砍掉全部 edge。
3. **顺逆分层必须防前视**：日线 EMA 趋势要用**前一交易日**收盘后已确定的值，否则盘中决策偷看当日收盘。
4. **shuffle 打错对象会得出假显著**：若把「顺势」和「size 过滤」一起打乱，测的就不是「顺势」。
   实测：单独打乱顺势标签 ⇒ p=0.23（不显著），真正驱动是 **size（大 bar）过滤**。
5. **单边年制造「最差年为负」**：2026 是 IM 单边下跌年 ⇒ 全族最差年落在 2026。分层（顺势/方向）
   可把最差年救回为正，但**这是诊断信号，不是放行理由**（过拟合风险同步上升）。
6. **R 缓存（工程要点）**：R 按 `(事件, 入场式, 持仓, 目标)` **只撮合一次**，再按任意过滤组合切片。
   否则「加一个维度就重跑一遍撮合」= 时间爆炸 + 各切片易不同源。
7. **成本改公共库前先查消费面**（§10.5 多形态交叉：import 形态 × 属性访问 × subprocess 路径 ×
   config 载体 + tokenize 独立交叉），并明确回答「会不会改动历史结论数字」——
   实测本次真实消费方只有 1 个且不用该函数 ⇒ 零历史影响，这才敢改。
8. **⚠️ 成本分母混淆（最隐蔽的一条，2026-09-23 实证）**：
   `R_net = R_gross − cost_R`，而 `cost_R = 费用(元) / (risk_pts × mult)`
   ⇒ **risk 越大，cost_R 越小**。若分组/暴露变量与 risk 相关（如「bar 相对大小」∝ risk），
   则**即使毛期望与该变量毫无关系，净 R 也会自动跟它正相关** ⇒ 造出「显著」，实为伪影。

   **实证（同一判据四品种）**：

   | 品种 | `corr(size, 成本R)` | 净 R 下 size p | **毛 R 下 size p** | 判定 |
   |---|---|---|---|---|
   | IM | −0.460 | 0.555 | 0.770 | 不显著 |
   | **MA** | −0.484 | **0.015** | **0.400** | ⚠️**成本伪影** |
   | SA | −0.423 | **0.000** | **0.000** | ✅真实关系 |
   | FG | −0.496 | **0.000** | **0.010** | ✅真实关系 |

   **判据（必做）**：凡**含成本**的 R 做分组/暴露检验，**必须同时跑一遍「毛 R（零成本）」**：
   - 净显著 + 毛不显著 ⇒ **伪影**，该结论作废
   - 毛仍显著 ⇒ 关系真实（**但仍须看毛期望的绝对水平** —— SA/FG 毛关系真实，毛 E[R] 却仍是 −0.07~−0.13，不可交易）
   - 并且直接量机理：`corr(暴露变量, cost_R)` 与 `Spearman(暴露变量, risk)` 应可解释该伪影

   **推论（比单次结论更重要）**：**用 R 单位成本做分组比较时，任何与 risk 相关的分组变量都自带此偏差**
   （典型：bar 大小 / ATR / 波动率 / 止损宽度 / 周期）。要么用毛 R 复验，要么把成本改成**绝对金额**口径。
9. **成本在 R 单位下与品种直觉相反**：费率低的品种未必便宜 —— 实测商品 MA/SA/FG 的 **R 单位成本
   （0.163 / 0.308 / 0.402 R）反而比 IM（0.029 R）高 5.5~13.7 倍**（因商品 risk 中位仅 6~9 点，
   滑点 2 点即占 22%）。⇒ **跨品种比较必须用 R 单位成本，不能用「费率高低」直觉替代。**

10. **⚠️ 分母异常小 ⇒ R 被放大百倍（2026-09-27 实证：0.67% 样本翻转结论符号）**：
    实盘台账 603 笔三价位决策，回采 598 笔得 `E[R]=+0.3470 / PF=1.606`
    —— **与既有基线 +0.356/1.57 高度吻合**，但 `trim3_R=−0.0439`、`best_R=114.47`。
    核 risk 后：**仅 4 笔 risk<5 点**（其中 3 笔 `risk=0.40`），剔除后
    **`E[R] +0.3470 → −0.0613`、`PF 1.606 → 0.894`** ⇒ 4/598＝**0.67% 的样本决定了符号**。

    **根因**：上游信号封装层在「结构位落错侧」（多单 stop ≥ entry）时，强制
    `stop = entry ± 2×tick`（IM tick=0.2 ⇒ **0.4 点**）以防除零，并打标 `guard_fix`。
    那是**兜底值、不是可交易止损**（0.4 点 ＝ 指数的 **0.0057%**，市场噪声瞬间打掉），
    却被当作计划止损进了绩效统计 ⇒ **分母趋零**。

    **判据（必做）**：
    - 算 E[R] 前先看 **risk 分布**（`P0/P1/P5`）与 **`risk_median`**；`risk_median` 缺失即报表有缺口
    - 守卫阈值：`risk < max(绝对下限, 0.25 × 当周期 ATR)` ⇒ **拒收 + 分类计数**（禁静默吞）
    - **分层治本**：上游兜底管「别出除零错」，**统计层**管「这条有没有绩效统计资格」——
      不要为报表去改上游（会破坏防御），应在统计层加资格闸
    - **陷阱识别**：「与既有基线完美吻合」**不等于**正确，可能正是假值造成的巧合 ⇒ 必须查分母
    - 附带教训：**判据写在 docstring 里 ≠ 有防线** —— 本例 `stats()` 早已写明
      「risk 极小时 R 会被放大百倍」，但未实装 ⇒ 假值照样进了报表


## 5. 交付门槛（缺一不许说「有 edge」）

- [ ] **risk 尺度已核**（分布 + `risk_median`）；无「上游兜底值（如 ±2tick）被当计划止损」的样本
- [ ] 赔率、成本、真值**三者皆实测**（无假设、无零成本、无代理量）
- [ ] 成本走**公共库唯一实现**，持仓周期口径已声明（日内/跨日费率不同）
- [ ] 分年表 + **最差年**（不是只报均值）
- [ ] 同源断言 / IS·OOS / shuffle / 邻域单调 **四验齐全**
- [ ] **含成本的 R 做分组/暴露检验时，同时跑「毛 R（零成本）」复验**（净显著+毛不显著=伪影）
- [ ] 与 risk 相关的分组变量（bar 大小/波动/止损宽度/周期）已识别，并说明是否受成本分母影响
- [ ] 跨品种比较用 **R 单位成本**，不用「费率高低」直觉（实测商品反而比股指贵 5.5~13.7 倍）
- [ ] `evalkit` 四件套 + `k*` / `trim25%` 脆弱性判定
- [ ] 配置总数与通过数（通过率）公开，并说明是否默认过拟合
- [ ] 用词纪律：通过四验也只说「**候选族**」；要说「edge」需再带 LLM / 盲测
- [ ] 0 LLM 产物一律标注「只作机制/统计证据，不作决策依据」
